# assets/

Drop Joseph's profile photo here as **`joseph-avatar.jpg`** (a square-ish
headshot works best — it gets center-cropped to a circle, biased toward the
face). Once it's here, every X-post style social card uses it as the avatar
automatically. If it's missing, the cards fall back to a "JB" monogram.

Accepted filenames (first found wins): `joseph-avatar.jpg`, `joseph-avatar.png`,
`avatar.jpg`.
