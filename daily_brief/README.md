# Shorts Creation Daily Brief

The "Shorts Creation Daily Brief" email is generated by a **Google Apps Script**
project (not by this repo's Python). This folder is the source-of-truth copy of
that script so it is versioned and reviewable.

- `Code.gs` — the brief itself: calendar, client snapshot, news, video ideas, email send.
- `Dropbox.gs` — pulls live raw/review/final/posted counts from Dropbox (unchanged).
- `appsscript.json` — project manifest.

## What changed (news + video ideas)

The old brief surfaced junk like *"Seven best sites to buy Instagram followers"* and
gave every article the same canned line (*"Explain what X means…"*) because it pulled
from **Google News RSS** — whose links are redirect URLs with **no article summary**,
and whose only spam filter was a short geo blocklist.

This version fixes both:

**Better news selection**
- Pulls from real **publisher RSS feeds** first (Social Media Today, Search Engine
  Journal, Later, Buffer, Hootsuite, Sprout Social, Tubefilter, TechCrunch, The Verge,
  TikTok Newsroom, YouTube Blog). These give a **direct link + a real summary**.
- Google News is now only a **fallback** to fill empty slots.
- Hard **spam blocklist** (`SPAM_BLOCKLIST`) kills "buy/free/cheap followers", SMM panels,
  affiliate listicles, "best sites to…", crypto/side-hustle bait, etc.
- Scoring now rewards **actionable / get-seen / make-better-video** signals
  (algorithm, reach, engagement, new feature, update, how-to, growth) and trusted
  sources, and rejects bare category titles like "Social Media Platforms".

**Better video ideas** — each news article now becomes a real brief:
- **What it's about** — a plain-English context line from the article's own summary.
- **Hook → Body → Cut/CTA** — what to say on camera.
- **Caption** — a full, ready-to-post caption with hashtags and the `@shortscreation` CTA.
- The article's direct link is shown right above it.

**Optional (sharper output):** set `ANTHROPIC_API_KEY` in Script Properties and the
brief uses Claude to write the context/hook/body/caption from each article's
title+summary. Without a key it still produces a full brief from smart templates —
no key required.

## How to deploy (paste into Apps Script)

1. Open the **"Shorts Creation Daily Brief"** Apps Script project
   (script.google.com → the project, or from the Drive file of the same name).
2. Open the `Code.gs` file there, select all, and replace it with the contents of
   `daily_brief/Code.gs` from this repo. **Save.**
3. Leave the `Dropbox` script file as-is (this repo's `Dropbox.gs` is just a backup copy).
4. Run `debugNewsSelection` once and check **Executions / Logs** — you should see real,
   on-topic headlines with `sum:Y` (a real summary attached).
5. Run `sendDailyBrief` once to send yourself a test brief. The daily 8 AM trigger
   (set up by `setupDailyBrief`) keeps using the updated code automatically.

### Optional Claude upgrade
Project Settings → **Script Properties** → add property `ANTHROPIC_API_KEY` =
your Anthropic key. (Optionally change `CONFIG.claudeModel` to `claude-sonnet-4-6`
for higher-quality captions; the default `claude-haiku-4-5-20251001` is cheap and fast.)

## Tuning knobs (top of `Code.gs`)
- `CONFIG.articlesToShow` — how many articles + news video ideas (default 3).
- `CONFIG.maxArticleAgeHours` — how fresh articles must be (default 96h).
- `NEWS_FEEDS` — add/remove publisher feeds.
- `SPAM_BLOCKLIST` / `OFFTOPIC_BLOCKLIST` — add any phrase to ban it forever.
- `GROWTH_TERMS` / `ACTIONABLE_TERMS` — add terms to boost the topics you care about.
